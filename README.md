# Assignment-2-ML

Dataset Description
Breast cancer is one of the most common cancers among women worldwide. This cancer occurs when breast cells grow abnormally, forming tumors.

The data used in this set is Wisconsin breast cancer data, sourced from the Kaggle platform. This set contains 30 numerical features that describe the characteristics of cell nuclei extracted from breast tissue images.

Machine Learning Problem
This is a supervised binary classification task.

The goal is to build a model that predicts whether a tumor is malignant or benign using the diagnostic features of the dataset.

The target variable in this set is the "Diagnosis" column, which indicates whether the tumor is malignant (M) or benign (B).
